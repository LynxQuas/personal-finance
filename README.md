# Personal Finance

A personal finance app for tracking income and expenses.

I built this project to practice building a frontend application with React and TypeScript, with a focus on managing financial data and keeping the UI simple.

## Features

* Track income and expenses
* Add, edit, and delete transactions
* View financial summaries
* Categorize transactions
* Filter financial data
* Responsive UI

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* shadcn/ui

## Running locally

```bash
git clone https://github.com/LynxQuas/personal-finance.git
cd personal-finance
npm install
npm run dev
```

Then open `http://localhost:5173`.
